ბრტყელი დიზაინი იმარჯვებს

უკვე ათი წელია, თითქმის ყველა პროდუქტის ინტერფეისი ერთ ვიზუალურ ენაზე „ლაპარაკობს”: თხელი ბორდერები, ერთ ტონში შერჩეული ფერები, ჩრდილების გარეშე.  მთელი აქცენტი კი ტიპოგრაფიაზეა გადატანილი. მიდგომა სუფთაცაა და სწრაფად ასაწყობიც, მაგრამ ბოლო დროს თითქოს ღირებულება დაკარგა. ეკრანები აღარ იგრძნობა ხელშესახებად, უბრალოდ სქროლავ და მორჩა.

სწორედ ამან მოიტანა 2026 წელს Soft UI-ის დაბრუნება. დიზაინის გუნდები ისევ ცდილობენ, ინტერფეისს სიღრმე და სითბო დაუბრუნონ, ოღონდ ამჯერად ბევრად უფრო გააზრებულად და დახვეწილად, ვიდრე ეს პირველ ჯერზე გამოვიდა. თუ წელს რედიზაინს გეგმავთ, ეს ის მიმართულებაა, რომელიც ჯერ თავად უნდა შეისწავლოთ, სანამ ვინმეს დავალებას გადასცემთ.

რას ნიშნავს Soft UI 2.0 სინამდვილეში

Soft UI 2.0 არის დაბრუნება ისეთ ინტერფეისებთან, რომლებიც ისე გამოიყურება და მუშაობს, თითქოს ფიზიკურ სივრცეში არსებობდეს, ოღონდ skeuomorphism-ის ტყავის ტექსტურებისა და ყველაფერზე დადებული ჩრდილების გარეშე. ლეიერებს მსუბუქი სიმაღლე უჩნდებათ. ღილაკს აქვს Default და Pressed მდგომარეობები, რომელიც მართლა დაჭერილს ჰგავს. ბარათები ფენებად აღიქმება და არა უბრალოდ ერთმანეთზე დაწყობილ ბლოკებად. მოძრაობას აქვს წონა: ელემენტები ისე ჩნდება და ქრება, როგორც ფიზიკური მასის მქონე ობიექტი მოიქცეოდა.

„2.0″ აქ შემთხვევითი არაა. ეს რამდენიმე წლის წინანდელი ნეომორფიზმის უბრალო დაბრუნება არ არის. ეს იმ დროის შეცდომებზე ნასწავლი, ბევრად უფრო დისციპლინირებული და ხელმისაწვდომი ვერსიაა.

რით განსხვავდება 2019 წლის ნეომორფიზმისგან

ნეომორფიზმის რბილი, ამობურცული, ერთ ფერში გაკეთებული სტილი, რომელიც რამდენიმე წლის წინ დიზაინერებში მოდაში იყო, Dribbble-ის სქრინშოტებზე ეფექტურად გამოიყურებოდა, რეალურ პროდუქტში კი ინგრეოდა. ღილაკი და ფონი თითქმის ერთ ტონში იყო, კონტრასტი იკარგებოდა და გამოყენებადობის ნებისმიერი აუდიტი მაშინვე წითელ ხაზს უსვამდა. ინტერაქტიულ ელემენტს დეკორაციისგან ვეღარ არჩევდი. ეს იყო სქრინშოტისთვის შექმნილი სტილი და არა რეალური გამოყენებისთვის.

Soft UI 2.0 ინარჩუნებს იმავე ტაქტილურ ენას, მაგრამ ასწორებს იმას, რამაც წინა ვერსია ჩააგდო. კონტრასტი უკვე სავალდებულოა. ფერი ისევ საქმეს აკეთებს: მშვიდი, დაბალი ინტენსივობის ტონები ერთი მკაფიო აქცენტით და არა ყველაფერი ერთ ტონში ჩაძირული. სიღრმე იერარქიისა და ინტერაქციულობის საჩვენებლად გამოიყენება და არა უბრალოდ სილამაზისთვის. ეს სტილი ნეომორფიზმისგან სითბოს სესხულობს, ბრტყელი დიზაინისგან კი იმ დისციპლინას, რომლისთვისაც თავის დროზე შეაქეს.

რატომ რბილდება ინტერფეისი ისევ

ამას ერთდროულად რამოდენიმე ფაქტორი განაპირობებს. AI-ით დაგენერირებულმა განლაგებებმა და შაბლონურმა საიტ-ბილდერებმა სუფთა ბრტყელი მინიმალიზმი უსახური გახადა. ის იმ ხელსაწყოების იერსახედ იქცა, რომლებზეც დიზაინერს ხელი არ დაუდია. ამიტომ ხელით ნაკეთები სიღრმე და ტექსტურა ისევ ხარისხის ნიშნად იკითხება. სივრცითმა და შერეული რეალობის ინტერფეისებმა ყურსასმენების ოპერაციული სისტემებიდან მობილურის შუშისებრ ფენოვან პანელებამდე გამჭვირვალობა, სიმაღლე და მასალები ყოველდღიური UI ლექსიკის ნაწილად აქცია და სიახლედ აღარ აღიქმება. მოძრაობაც გაიაფდა: GPU-ზე აჩქარებული CSS, მომწიფებული ანიმაციის ბიბლიოთეკები და სწრაფი მოწყობილობები ნიშნავს, რომ მიკროინტერაქციები, რომლებიც ადრე წარმადობის რისკი იყო, დღეს უპრობლემოდ ეშვება.

არის ნდობის ფაქტორიც. ფინტექი, ჯანდაცვა და სხვა მაღალი პასუხისმგებლობის პროდუქტები შეგნებულად მიდიან უფრო რბილი, ტაქტილური მიმართულებით, რადგან ის უფრო ადამიანურად აღიქმება, ვიდრე ცივი ბრტყელი ინტერფეისი – სწორედ მაშინ, როცა მომხმარებელი სულ უფრო ეჭვით უყურებს ყველაფერს, რაც ავტომატიზებულს ან შაბლონურს ჰგავს.

როგორ გამოიყურება ეს პრაქტიკაში

რამდენიმე კონკრეტული ნიშანი, რაზეც ყურადღება უნდა გაამახვილოთ და დიზაინერსაც მოსთხოვოთ:

რბილი, მიმართულების მქონე ჩრდილები ბრტყელი drop shadow-ის ნაცვლად – ისე, თითქოს სინათლე მთელ ინტერფეისში ერთი წერტილიდან მოდიოდეს. ნახევრად გამჭვირვალე ზედაპირები, რომლებიც სიღრმეს გაგრძნობინებს მძიმე სკევომორფული ტექსტურების გარეშე. გააზრებულად გამოყენებული მომრგვალებული გეომეტრია. არა უბრალოდ ყველგან დამრგვალებული კუთხეები, არამედ ფორმები, რომლებიც რეალურ შეხების წერტილებს იმეორებს. თავშეკავებული, მშვიდი ფერთა სისტემა ერთი თამამი აქცენტით და არა ბრტყელი ბლოკების ცისარტყელა. შეხებაზე მიბმული მიკროინტერაქციები: ღილაკი, რომელიც თაჩზე შესამჩნევად იკუმშება; გადამრთველი, რომელიც ეასინგით სრიალებს და არა ნახტომით; ბარათი, რომელიც hover-ზე ოდნავ მაღლა იწევს. და გულუხვი შიდა padding, რომელიც ელემენტებს სუნთქვის საშუალებას აძლევს კიდიდან კიდემდე გაჭედილი ბლოკების ნაცვლად.

ეს ეფექტების გადაჭარბებას სულაც არ ნიშნავს. საუკეთესო მაგალითები ზომიერებით გამოირჩევა – ერთი-ორი კარგად გაკეთებული დეტალი სჯობს ხუთ ნახევრად გაკეთებულს.

რას ნიშნავს ეს, თუ რედიზაინს განიხილავთ

ცდუნება დიდია, ეს უბრალო ვიზუალურ განახლებად აღვიქვათ: დავამატოთ ჩრდილები, დავამრგვალოთ კუთხეები და გავუშვათ. სინამდვილეში საქმე ბევრად მეტია. Soft UI-ის სისტემას სჭირდება ერთხელ განსაზღვრული და ყველგან თანმიმდევრულად გამოყენებული სიმაღლის ტოკენები და არა ეკრანიდან ეკრანზე თვალის ზომით დადებული ჩრდილები. სჭირდება კონტრასტის რეალური შემოწმება – ზუსტად ის ხაფანგი, რომელშიც ნეომორფიზმი გაება – ამიტომ გამოყენებადობის ტესტირება პროცესის ნაწილი უნდა იყოს და არა ბოლოს მოსაფიქრებელი დეტალი. სჭირდება მოუშენის ბიუჯეტი: წინასწარ გადაწყვეტა, რომელი ინტერაქცია ანიმირდება და რომელი დარჩება სტატიკური, რომ ინტერფეისი მეტად ცოცხალი იყოს.

კრედო ბანკის SMART Deposit-ის კალკულატორზე მუშაობისას სწორედ ეს სიცხადე იყო მიზანი: ფინანსური ინსტრუმენტი, რომელიც ხელმისაწვდომი და ნაბიჯ-ნაბიჯ სამართავი იქნებოდა და არა დამაშინებელი. იგივე ინსტინქტი დგას დღეს Soft UI 2.0-ის უკანაც – ინტერფეისები, რომლებსაც ხელით ეხები და არა მხოლოდ თვალით კითხულობ.

ღირს ამ თემის დაკავშირება იმასთანაც, თუ როგორ მოძრაობს ინტერფეისი და არა მხოლოდ როგორ გამოიყურება სტატიკურად. ამაზე ვრცლად დავწერე პოსტში „რატომ სჭირდებათ ბრენდებს, მოძრავი იდენტობა და არა უბრლოდ ლოგო” – იგივე ლოგიკა ინტერფეისის დონეზეც მუშაობს: სიღრმე და მოძრაობა ერთად უნდა დაიგეგმოს და არა ბოლოს ცალ-ცალკე მიეკეროს.

თუ წელს რედიზაინზე ფიქრობთ, დიზაინერისთვის დასასმელი კითხვა არაა „ჩრდილებს ხომ ვერ დაამატებ”. კითხვები ასეთია: აქვს თუ არა სისტემას სიმაღლისა და მოძრაობის განსაზღვრული წესები; შემოწმდა თუ არა კონტრასტი წესიერად; და ემსახურება თუ არა ეს სირბილე გამოყენებადობას თუ მხოლოდ ესთეტიკას. თუ ამას სწორად გააკეთებთ, Soft UI 2.0 ტრენდი აღარ იქნება – უბრალოდ კარგი, ადამიანური ინტერფეისის დიზაინი გახდება.
